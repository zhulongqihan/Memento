# 4.2 严格审阅与阅读品质提升

用户于 2026-10-30 要求重新以专业评审、苛刻用户视角全面检查，并继续提升前端。4.1.0 的已验收修复作为基线，不把“先前问题关闭”当成“所有场景没有问题”。

## 工作与验收

1. 独立 A 设计评审、B 检测与浏览器证据、工程交互审阅；A 完成前不将 B 的检测结论用于设计判断。
2. 确认实际问题的复现、影响与根因，先修功能和可读性，再完善页面气质。区别确定缺陷与审美判断。
3. 四页保留各自的空间与时间含义；以清晰字号、精确排版、细线和用户真实内容提升品质。控件使用无衬线、时间使用等宽数字、标题与长篇回看保留衬线。
4. 重点验收长内容、空状态、三个桌面尺寸、三种主题、两种密度、键盘与 reduced motion，以及记录、保存、备份的现有闭环。
5. 独立版本分支 `codex/memento-v4.2-editorial-refinement`，基于 4.1 的候选；生成安装包、校验和来源证据，通过检查后提交后续 PR。未经用户明确要求不合并、不正式发布。

## 范围边界

不访问用户正式数据库、不在本机启动正式 exe。私人秋招副本只用于本机效果复测，原表只读，源数据和截图不进入提交或 CI。合成数据承担自动回归。保持 schema v4；不增加社交、账号、AI 或任务管理。
