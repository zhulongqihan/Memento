## 验收与发布后复核

65 项前端、2 项 Rust、类型检查、生产构建、1000 条文案检查以及 13 组浏览器流程/回归通过。正式安装版与便携版在独立 hosted Windows VM 完成八项原生验收：新装首屏、卸载保留、真实 3.1.0 升级基线、升级不改旧状态、迁移故障保留与重试、坏图编辑、替换恢复、最终卸载保留。页面异常为空。

下载后的失败 SQLite 快照为 schema 3/failed，成功快照为 schema 4/committed；独立只读完整性、三表和哈希复核通过。成功状态与恢复状态完整保留旧时刻、经年、余下、阶段、每日一行、旁白使用/收藏及全部设置。69 字节合成照片与旧内嵌字节、索引及报告一致。此前直接复制 WAL 主文件的归档缺陷已改为一致性导出并关闭。

原生 WebView 五组视口为 1440×900；浏览器四页覆盖 1280×720、1440×900、1920×1080。最终 tag 的首屏、恢复照片、几度与每日历史截图已查看，无横向溢出或按钮挤压。操作列改为 max-content；发布前独立六组几何检查均保持数字/按钮 13px 间距，按钮至少 32×32px。

四类发布后审阅均通过：[产品](reviews/4.0.0-product.md)、[视觉](reviews/4.0.0-visual.md)、[数据安全](reviews/4.0.0-data-safety.md)、[工程](reviews/4.0.0-engineering.md)。

## 交付与边界

安装包与便携版目前均未做 Authenticode 代码签名，校验文件已提供。缺少 WebView2 Runtime 时首次安装需联网下载。安装面向当前 Windows 用户，卸载默认保留数据。未完成完整读屏、全 WCAG、全部系统缩放/WebView2 版本或长期性能认证。

历史一次仅设置 APPDATA 的正式 portable 启动可能解析到真实用户数据库，影响未知；之后不读写、迁移或恢复真实数据库。独立 VM 通过不能反证历史影响。此前本机 Known Folder 注册表重定向在执行前被工具拒绝，没有该写入，也不换方式绕过。本轮正式程序验收只在 hosted VM 使用合成数据；本机只构建、浏览器合成测试、只读解包及下载证据复核。

本轮收尾清单见 [完成计划](plans/v4-completion.md)。项目进入正常使用与维护阶段，后续版本按实际问题排定。历史候选与诊断见 [发布前记录](https://github.com/zhulongqihan/Memento/blob/4f8892a0d627cd34cbbc423d6f5ad034dafa012f/docs/current-state.md)。无关原有文件保持保留。
