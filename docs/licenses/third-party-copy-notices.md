# 第三方文案许可说明

Memento 3.1.0 的静态文案资源仅包含两类来源：

1. `gujilab/chinese-classical-corpus` 的数据集输出，按其数据集说明使用 CC0 1.0。来源页：[Hugging Face 数据集](https://huggingface.co/datasets/gujilab/chinese-classical-corpus)，许可页：[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)。
2. Project Gutenberg 公共领域作品的短句，来源页保留在每条文案记录中；通用许可说明：[Project Gutenberg License](https://www.gutenberg.org/policy/license)。

外文条目的中文译文由 Memento 编译，不是第三方译文。若后续加入 CC BY 或 CC BY-SA 条目，必须为每条记录增加署名、原始链接、修改说明和相同/兼容许可信息；未经审计不得加入发布包。

本项目没有将 Chinese Text Project 的 CC BY-NC-SA 数据直接打包，因为该许可包含非商业限制，与本地发布包的长期使用场景不匹配。
