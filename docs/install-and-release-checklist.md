## 发布时需保留的约束

- 只用隔离目录与合成记录；不覆盖真实 `%AppData%` 数据库。
- 安装器采用 currentUser 模式。若没有 WebView2 Runtime，首次安装需要联网下载。
- 卸载默认保留用户数据。
- 研究截图不等于完整 WCAG、屏幕阅读器或原生存储认证；未验证的项目需明确写出。
- P0/P1 未关闭时不进入发布 PR；不以发布说明掩盖数据损坏或缺失证据。
