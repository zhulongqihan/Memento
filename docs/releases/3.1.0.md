# Memento 3.1.0

发布日期：2026-08-28
发布类型：根目录可直接运行版，不生成 NSIS/MSI 安装包。

## 本次更新

- 增加随软件打包的 1000 条本地授权文案库，运行时不请求网络。
- 增加每日一行：每个本地日期最多保存一条，可编辑、删除、备份和恢复。
- 增加今日旁白：本地随机、按已展示条目去重、收藏、复制、查看来源和转为每日一行。
- 增加河流漂流覆盖层：最多 5 个真实内容片段，支持鼠标水纹、自动推进、暂停、键盘方向键、Enter 和 Escape。
- 旁白、每日一行和收藏快照纳入 schema v3、SQLite 保存和 JSON/ZIP/加密备份。
- “我的”页增加文案来源与授权说明；原有四页视觉世界和主导航保持不变。
- 实时钟秒数统一补零显示，低动态模式关闭漂流自动播放与连续水纹。
