# 几度 · Memento 4.2.0

状态：候选验收通过，可安装；[PR #6](https://github.com/zhulongqihan/Memento/pull/6) 尚未合并，尚未正式发布。该 PR 基于仍未合并的 4.1 PR #5，正式公开版本仍为 v4.0.0。

## 改动

- 编辑时保持原记录身份；有修改的草稿在关闭、Esc、背景点击或切换类型时确认放弃。
- 午夜、唤醒和窗口恢复焦点时同步本地日期；跨日草稿明确保留原日期。
- 每日一行删除统一确认，空白保存不会删除原记录。时光搜索与视图选择在切页后保留。
- 人生年限在保存前验证 1–150 整数；普通 JSON/ZIP 导出错误有明确反馈。
- 四页重新统一阅读字号、排版与操作层级，保留此刻、时光、几度和我的各自的视觉身份。
- 修复深色文字、空态按钮、设置辅助文字；长内容在预览中省略、详情中完整换行；紧凑模式实际缩小行距。
- 设置页按备份、加密、恢复和清空分组；缩短页面过场，尊重 reduced motion。
- 自动旁白关闭时显示关闭说明与开启位置，不再误报文案库耗尽。

## 数据与验证边界

仍使用 schema v4，不改变备份格式或放宽照片完整性检查。自动测试仅使用合成数据，私人秋招样本只保存在本机 ignored output。本轮实际场景复测沿用上次副本；当前源表已有变化，不声称副本是最新投递状态。

本机只运行浏览器与构建，未访问正式数据库，也未运行正式安装版/便携版。Windows 原生验收在独立 hosted VM 使用合成数据。未宣称完整读屏、全 WCAG 或所有系统缩放认证。

## 验收结果

[Quality](https://github.com/zhulongqihan/Memento/actions/runs/42063606586) 与 [Windows Candidate](https://github.com/zhulongqihan/Memento/actions/runs/42063606572) 均成功。通过 77 项前端单元、2 项 Rust、类型检查、生产构建、1000 条文案校验、13 组原浏览器流程、6 组阅读检查、8 组状态流程、116 项视觉及输入边界检查。

四页覆盖 1280×720、1440×900、1920×1080，覆盖浅色、深色和高对比。另检查设置子页、空态、长内容、密度与 reduced motion。浏览器与原生页面错误均为空。

最终安装包与便携程序完成 8 项 Windows 原生验收：新装首屏、卸载保留、真实 3.1.0 升级基线、升级不改旧数据、迁移故障保留与重试、坏图引用编辑、替换与快照恢复、最终卸载保留。

下载后独立只读核对两个合成 SQLite 快照：完整性均正常，失败状态保留 schema 3，成功状态为 schema 4；recovery、业务字段、设置、照片哈希与字节均保留正确。没有读取用户正式数据库。私人旧副本 8 项本地复测通过。
