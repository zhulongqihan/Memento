# 几度 · Memento 4.1.0

状态：候选版本，尚未正式发布。正式公开版本仍为 v4.0.0。

## 改动

- 自然日倒计时显示“还有 N 天”“今天”“已过 N 天”，主测量、列表、首页、漂流和分享卡使用同一日期解释。
- 新建余下可选择“自然日（每天）”；已有自定义星期全选记录直接兼容，无需数据迁移。周期计数明确区分截止日与计入日，周末按周六、周日各一天说明。
- 纯文字记录直接展示真实发生日期、标题与笔记；详情不再显示空照片框或写死的“第一个”。缺失照片仍保留引用与恢复提示。
- 默认时间索引增加月份定位与标题、笔记、地点搜索，区分结果数与总数；无结果可清除条件。
- 修复首次方向键跳过第一条记录，月份跳转同步键盘焦点并尊重 reduced motion。
- 收紧索引首屏介绍与无图胶片占位，提高日期、摘要和深色计数单位的可读性。
- 构建与证据目录按版本生成，避免新安装包覆盖旧版产物。

## 兼容与数据

持久化仍是 schema v4。自然日以旧格式 `custom + [0,1,2,3,4,5,6]` 保存，既有星期计数与备份可继续使用。没有新增账户、网络服务或提醒任务。私人试用数据未放入仓库、安装包或 CI，自动验证使用合成记录。

## 验证

已通过 77 项单元测试、类型检查、生产构建、1000 条文案校验、原有浏览器照片／编辑／导入／恢复回归，以及新增阅读与日期浏览器检查。三个桌面尺寸与三种阅读主题的关键文字已检查；未宣称完整 WCAG 或完整读屏认证。

Windows 安装包与便携版正在按当前提交生成，校验值和清单随产物保存。原生安装／升级／迁移／卸载验收继续在 hosted Windows VM 上用合成数据执行；本机不启动正式程序或访问用户正式数据库。

## 已知交付边界

安装包尚无 Authenticode 签名；缺少 WebView2 Runtime 时首次安装可能需要联网下载。候选版本验收通过后再决定正式发布。
