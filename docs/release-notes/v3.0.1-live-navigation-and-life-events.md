# Memento v3.0.1

## 本次修复

- 左侧导航随页面世界切换材质：此刻为实时墨绿、时光为档案纸、几度为仪器黑、我的为登记册灰。
- 此刻背景改为低干扰的聚焦光场，移除晕眩的同心波纹；时钟每秒刷新一次，秒数和当天进度同步变化。
- 此刻没有记录时，“记下第一件事”会直接打开记录抽屉；有置顶记录时，“打开这段时光”会打开详情。
- 在当前本地时间册中加入用户确认的六条人生节点。仅出生使用 `2002-10-25`，其余年份使用可编辑的月份锚点，并在记录备注中标明。
- 版本号从 3.0.0 迭代到 3.0.1。

## 交付

- 直接运行版：[Memento.exe](../../Memento.exe)
- 不生成 NSIS/MSI 安装包。
- 本次发布前保留了本地数据库快照，文件位于 `output/memento-before-life-events-20260827.db`（该目录不纳入提交）。
- 校验值见 [v3.0.1-Memento.exe.sha256](v3.0.1-Memento.exe.sha256)。
