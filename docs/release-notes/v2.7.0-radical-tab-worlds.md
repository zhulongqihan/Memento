# Memento 2.7.0 · 四页独立视觉世界

## 这次解决的问题

2.6.0 已经拆出了四个页面组件，但视觉规则仍然共享“浅底、页眉、横线、内容块”的节奏，导致图片像插入物，四个 Tab 仍然像同一页的换图版本。

2.7.0 将主内容改成四种真正不同的页面空间：

- **此刻 · 运行中的时间舞台**：深墨色时钟主屏、荧光绿校准线、中央观察窗与即时记录入口。
- **时光 · 胶片档案墙**：暖灰纸张、朱红索引、横向月份档案和接触印样式的记录证据。
- **几度 · 时间测量仪器**：黑色仪表底、橙色刻度、单一测量主视图与精确的三方向切换。
- **我的 · 个人登记册**：克制的目录式设置布局、左侧身份登记、右侧数据操作和可预测的备份流程。

页面身份由 `data-world` 驱动；旧数据中的 `visualNarrative` 仍保留用于兼容，但不再决定页面布局。

## 动效与无障碍

- 四页使用不同的进入转场：纵向揭幕、横向胶片推进、圆形仪器展开、轻微档案翻入。
- 此刻的时钟和几度的校准点使用低频、可解释的状态动效。
- `prefers-reduced-motion: reduce` 会取消转场、呼吸和校准动画。
- 高对比模式隐藏装饰性照片，但保留标题、日期、数据和操作；照片加载失败仍显示同尺寸错误状态。

## 验证

- `npm run typecheck`
- `npm test`
- `npm run build`

本版本只改变展示层，不改变记录、照片、筛选、编辑、分享、导入、导出、恢复和清空保护逻辑。
