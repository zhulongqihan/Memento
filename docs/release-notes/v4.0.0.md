# 几度 · Memento 4.0.0

适用于 Windows x64。

## 本次更新

- 时光新增“每日一行”历史，可按月份回看、修改或删除，编辑时保留原来的日期。
- 一段时刻里的三张照片都能在详情中完整查看。照片暂时不可用时，会保留提示与关联；修改文字不会移除照片。
- 经年、余下和刻度编辑时保留原名称；经年与余下支持单条删除，已暂停的刻度可以重新启用。
- 照片独立保存，读取旧版本数据与备份时会校验照片，并在迁移前保留恢复快照。
- 替换导入和清空数据前保留本地快照；导入失败时保留原记录和已有照片。
- 改善桌面排版、筛选空态与键盘操作，支持减少动效和高对比设置。

## 安装与升级

下载 `Memento_4.0.0_x64-setup.exe` 并双击安装。也可使用 `Memento-4.0.0-portable.exe` 便携版。

升级前可在“我的”中导出一份完整 ZIP 或加密备份。v4 支持读取 v1、v2、v3 本地数据和备份；完成迁移后请继续使用 v4，避免用旧版程序写入已升级的数据。

安装仅面向当前 Windows 用户。若电脑尚未安装 WebView2 Runtime，首次安装需要联网下载运行时。卸载默认保留本地记录和照片。

每个 exe 都附带同名 `.sha256` 校验文件；`manifest.json` 记录本次产物的校验值及源码版本。

数据保存在本机，无需账户。JSON、完整 ZIP 和 `.memento` 加密备份可在“我的”中导出。
