# Memento v2.9.0

## 交付内容

- 此刻使用暗房档案结构，第二套样张仅作为此页的视觉方向。
- 时光改为连续时间索引，不再使用统一卡片骨架。
- 几度改为垂直子 Tab、单条真实校准尺和数据列表。
- 我的改为目录栏 + 当前文档的本地登记册。
- 四页增加不同的鼠标跟随背景层，并支持 reduced motion。
- 保留记录、照片、筛选、编辑、分享、导入、导出、恢复和清空确认逻辑。

## 版本与运行方式

- 版本从 2.8.0 迭代到 2.9.0，已同步 package、Cargo、Cargo lock、Tauri 配置和界面文字。
- 不生成 NSIS/MSI 安装包。
- 直接运行文件：[memento.exe](../../src-tauri/target/release/memento.exe)
- SHA-256：见 `v2.9.0-memento.exe.sha256`。

## 验证

- `npm run typecheck` 通过。
- `npm test` 通过：7 个测试文件、30 个测试。
- `npm run build` 通过。
- `npm run tauri build -- --no-bundle` 通过。
- Playwright 已验收四个 Tab、空数据、1280×720、1440×900、1920×1080、深色、高对比和 reduced motion。
