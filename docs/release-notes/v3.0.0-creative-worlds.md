# Memento v3.0.0

## 这次改变

四个 Tab 不再是同一套页面换颜色：

- 此刻：指针响应的活时钟镜面，时间波纹服务于“正在发生”。
- 时光：胶片档案墙，年份、月份和记录带构成真正的回看路径。
- 几度：低亮度时间测量仪器，唯一主尺由真实数据驱动。
- 我的：个人登记册，目录和设置文档保持安静、可信、可维护。

## 保留内容

记录、照片、筛选、详情、编辑、分享、备份密码、导入、导出、恢复快照、清空确认和旧备份字段均保留。visualNarrative 继续兼容，但不再决定新页面布局。

## 运行方式

本版本不生成 NSIS/MSI 安装包。构建后的可直接运行文件位于项目根目录：

[Memento.exe](../../Memento.exe)

校验值见 [v3.0.0-Memento.exe.sha256](v3.0.0-Memento.exe.sha256)。

## 验证

- npm run typecheck
- npm test
- npm run build
- npm run tauri:build（--no-bundle，随后同步根目录便携版）
