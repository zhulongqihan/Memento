# 几度 · Memento 视觉叙事实现批次

基于 v2.5.0 的四季 × 三种视觉叙事实现记录。

## 已交付

- 新增 `visualNarrative` 偏好：`archive`、`light`、`instrument`，旧数据和未知值安全回退到 `archive`。
- 根元素使用独立的 `data-visual-narrative` / `data-visual-story` 属性，与浅色、深色、高对比、舒适、紧凑和数字格式正交组合。
- “我的 → 外观与阅读”提供稳定位置的典藏、光影、刻度选择器：鼠标、Enter、Space 可应用，上下箭头只移动预览，应用后即时持久化。
- 四个主页面均提供三种真实布局：春·此刻、夏·时光、秋·几度、冬·我的，共 12 个页面状态。
- 光影使用项目内四季样片作为无照片降级；用户照片仍优先进入媒体槽位。
- 刻度页面最多一个主测量图，并提供文本等价表达；未引入天气、地图、医学、校准或保险库等生成图功能。
- 保留现有导出、加密备份、导入、替换前快照、恢复和危险操作保护。
- Windows 窗口最小尺寸为 1280×720，避免进入设计范围外的窄布局。
