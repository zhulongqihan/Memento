# Memento v2.8.0

## 四个真正独立的页面世界

2.8.0 重做四个 Tab 的主内容结构，不再以统一编辑页骨架叠加颜色和图片：

- 此刻：活时钟舞台，时间读数、观察窗和即时记录形成不对称舞台。
- 时光：胶片档案墙，年份、月份和固定尺寸证据片组成横向时间轴。
- 几度：时间测量仪器，三个子 Tab 共用一个真实数据驱动的 SVG 主测量图。
- 我的：个人登记册，目录栏与当前文档分离，备份和危险操作保持可预测。

## 兼容与发布

- 保留 `visualNarrative` 旧字段和导入兼容逻辑，但新布局不由它决定。
- 版本同步到前端、Cargo 和 Tauri 配置。
- 不生成 NSIS/MSI；直接运行版本为 `src-tauri/target/release/memento.exe`。
- 照片继续本地优先；无照片状态、加载失败、重试和高对比隐藏均有对应界面。

## 验证

`npm run typecheck`、`npm test`、`npm run build` 通过；Tauri 使用 `--no-bundle` 生成直接运行版本。
