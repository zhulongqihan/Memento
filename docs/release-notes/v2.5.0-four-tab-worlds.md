# Memento 2.6.0 · 四页固定视觉世界

日期：2026-08-26

## 本次更新

- 此刻改为呼吸时钟观察台：时间、进度、照片和记录入口形成不对称主舞台。
- 时光改为记忆胶片图谱：年份轴、月份索引和横向记录带共同承载照片与文字证据。
- 几度改为时间测量台：保留经年、余下、刻度语义，以单一主测量图呈现数据。
- 我的改为个人档案登记册：身份区、四页视觉地图、数据备份和设置分区更清晰。
- 页面切换增加按页面身份变化的转场，并支持 `prefers-reduced-motion`。
- 用户照片优先；无照片、图片失败和高对比模式均保留实色阅读面。
- 旧备份中的 `visualNarrative` 字段继续兼容，但不再决定四页布局。
