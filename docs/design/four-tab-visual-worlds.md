# Memento 四页固定视觉世界

> 状态：实现交接稿  
> 日期：2026-08-26  
> 适用范围：Windows PC，主设计尺寸 1440×900，验收宽度 1280–1920px

## 设计结论

四个主 Tab 不再由全局视觉叙事决定页面骨架，而是固定为四个任务明确、布局拓扑不同的视觉世界。数据、导航、编辑、筛选、详情、备份和安全流程仍共享同一底座。

| Tab | 视觉世界 | 主结构 | 图片角色 | 转场语言 |
| --- | --- | --- | --- | --- |
| 此刻 | 呼吸时钟 / Living Time | 时间列 + 观察舞台 + 记录侧栏 | 窗边生活标本，与时间构图 | 竖向光线展开 |
| 时光 | 记忆胶片 / Memory Atlas | 年份轴 + 月份索引 + 横向记录带 | 日期绑定的接触印证据片段 | 横向胶片推进 |
| 几度 | 时间测量台 / Time Instrument | 单一测量主视图 + 三个数据子 Tab | 辅助观察材料，不替代数据 | 圆形刻度展开 |
| 我的 | 冬夜档案室 / Personal Registry | 身份区 + 目录式设置分区 | 仅作身份和页面地图材料 | 深色档案页翻入 |

## 共享底座与兼容

- 保留 `PageId`、104px 左侧导航、记录入口、抽屉、详情、筛选、导入、导出、恢复和清空保护。
- `visualNarrative` 仍保留在序列化数据中，仅用于旧备份兼容和安全回退，不再决定页面布局。
- 页面身份通过 `data-world` / `data-page` 表达；主题、密度和数字格式仍是正交设置。
- 用户照片优先；无照片时使用项目内样片或同尺寸阅读面。图片失败不会影响正文和数据阅读。

## 动效边界

页面进入动画使用 `transform`、`opacity` 和有限 `clip-path`，时长约 500–640ms。重复点击由 React 页面身份更新自然取消旧页面动画；不刷新、不重置筛选、不关闭抽屉或清空表单。`prefers-reduced-motion: reduce` 下移除页面动画和图片缩放，仅保留焦点与选中状态变化。

## 验收重点

1. 1440×900 首屏仅凭结构即可区分四页，而不是通过换色或插图区分。
2. 1280–1920px 不出现横向溢出；标题、按钮、数据和焦点环可读。
3. 空数据、无照片、照片加载失败、单条记录和大量记录均有完整阅读面。
4. 浅色、深色、高对比、舒适和紧凑设置不破坏正文对比度与危险操作保护。
