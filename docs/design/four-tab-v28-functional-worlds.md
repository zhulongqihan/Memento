# Memento 2.8.0：四个功能隐喻页面世界

## 设计结论

2.8.0 不再用春夏秋冬定义页面。春夏秋冬只作为无用户照片时的本地辅助样片；四个 Tab 的身份来自用户任务和信息结构：活时钟、胶片档案墙、时间测量仪器、个人登记册。

## 页面拓扑

| 页面 | 主拓扑 | 媒体角色 | 动效语言 |
| --- | --- | --- | --- |
| 此刻 | 12 列不对称舞台：读数 / 观察窗 / 即时记录，底部全宽时间基线 | 一扇观察窗；无照片仍保留同尺寸观察场 | 竖向时间幕布展开，照片只做有限裁切 |
| 时光 | 年份尺 + 月份脊柱 + 横向胶片带 | 固定尺寸的接触印样或文字证据片 | 胶片门横向推进，左右键移动胶片 |
| 几度 | 垂直子 Tab + 唯一 SVG 测量图 + 数据列表 | 不使用照片 | 圆形刻度展开，测量线一次校准 |
| 我的 | 登记表头 + 目录栏 + 当前文档 | 不使用照片 | 文档页轻微翻入，目录焦点同步 |

## 状态和兼容

- `data-page` 是当前页面身份入口；`data-theme`、`data-density` 只改变阅读条件。
- `visualNarrative` 保留在数据模型和旧备份中，但不再控制页面布局。
- 备份密码草稿提升到 App 路由层，切换 Tab 不丢失；抽屉仍在路由外部，切换 Tab 不关闭。
- 时间轴滚动位置和几度子 Tab 由 App 层保存。
- 照片失败显示同尺寸错误面板和重试入口；高对比模式隐藏装饰样片但不隐藏正文。

## 验收记录

浏览器验收覆盖 1280×720、1440×900、1920×1080。四页根节点分别为 `clock-stage`、`film-wall`、`measurement-instrument`、`registry-document`，三种尺寸均无横向溢出。`prefers-reduced-motion: reduce` 下路由动画为 `none`。
