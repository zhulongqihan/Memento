# Memento 2.9.0：四个独立的界面语法

## 设计结论

2.9.0 不把第二套暗房视觉扩展成全局主题。它只属于“此刻”；另外三个 Tab 使用不同的材料、信息结构和鼠标反馈。四页共享数据、导航、记录抽屉、详情、筛选、备份和恢复能力，但不共享主内容骨架。

春夏秋冬不再承担页面身份，只保留为无用户照片时的本地辅助样片来源。

## 四个页面

### 此刻：暗房档案 / Living Darkroom

- 结构：顶部状态栏 + 时间列 + 纵向观察孔 + 即时记录栏 + 底部时间基线。
- 材料：石墨黑、骨白、低饱和暗房光和朱红秒标记。
- 内容重心：正在运行的时间读数；照片是窄幅观察证据，不是大图卡片。
- 无照片：保持同尺寸观察孔，显示日期、文字观察入口和明确的空状态。
- 指针反馈：低对比中性光束、同心暗线和一条扫描线随鼠标缓慢跟随；正文与按钮不漂移。

### 时光：连续索引 / Memory Index

- 结构：顶部年份尺 + 筛选 + 左侧月份脊柱 + 横向连续记录带。
- 材料：米白纸张、细网格、朱红定位线和棕黑文字。
- 内容重心：年月定位和记录连续性；有照片和无照片记录使用同尺寸证据槽。
- 空状态：只保留一格“第一条记录”与小幅辅助证据，不制造大面积图片背景。
- 指针反馈：垂直扫描线和低对比纵向光带指向当前时间位置；横向记录带继续可用键盘左右、Home、End 浏览。

### 几度：测量工作台 / Precision Bench

- 结构：左侧垂直子 Tab 索引 + 中央单条校准尺 + 右侧主读数 + 下方真实数据列表。
- 材料：黑色仪器底、低亮度网格、银灰文字和橙色校准线。
- 内容重心：经年、余下、刻度三个语义的真实数值和日期来源；不使用四宫格 KPI 或照片。
- 指针反馈：十字定位线和有限半径校准环跟随鼠标，用来强调测量关系，不改变数据。

### 我的：文档登记册 / Personal Registry

- 结构：个人身份与本地状态 + 一行登记数据 + 左侧目录 + 右侧当前设置文档。
- 材料：冷灰纸面、深灰绿色目录、低饱和状态色和细文档线。
- 内容重心：备份、导入、恢复、清空、人生进度、阅读条件；危险操作集中在数据文档中并保留确认提示。
- 指针反馈：纸面上的轻微定位框和坐标线；动效最少，不把设置页变成展示舞台。

## 指针动效约束

- 使用 `requestAnimationFrame` 将目标位置缓慢插值到装饰层，页面内容不参与位移。
- 只动画化 `transform`、`opacity` 和背景定位；不动画化布局尺寸、`top`、`left`、正文位置。
- 背景效果不覆盖正文，不使用蓝紫渐变、玻璃拟态、粒子、弹跳和持续装饰动画。
- `prefers-reduced-motion: reduce` 下隐藏指针装饰、取消路由转场和横向平滑滚动。
- 高对比模式隐藏非关键装饰和照片，但保留日期、标题、数据、表单和操作。

## 验收断言

- 四页根节点的 `data-layout` 分别为 `darkroom-live-time`、`film-index`、`precision-instrument`、`personal-registry`。
- 1280、1440、1920 宽度下页面文档宽度不超过视口宽度。
- 视觉差异来自布局拓扑、材料和交互反馈，不来自单纯换色。
- 2.9.0 保留旧数据字段和现有业务逻辑；本次不修改数据模型。
