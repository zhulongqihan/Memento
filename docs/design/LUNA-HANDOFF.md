请在 `F:\Memento` 内实现已经确认的“四季 × 三种视觉叙事”前端系统。不要重新发散设计，也不要根据生成图补造产品功能。

1. `F:\Memento\AGENTS.md`
2. `F:\Memento\PRODUCT.md`
3. `F:\Memento\DESIGN.md`
4. `F:\Memento\docs\design\README.md`

必须完整阅读，不能只看图片或摘要。书面规范优先于视觉参考图；图片里的错字、虚构数据、路径和设置项不得实现。

## 已确定的目标

- 固定页面映射：春·此刻、夏·时光、秋·几度、冬·我的。
- 增加三种视觉叙事：典藏、光影、刻度；默认典藏。
- 在“我的 → 外观与阅读”中提供即时、可持久化、键盘可操作的视觉叙事选择器。
- 保留现有浅色、深色、高对比、页面密度和数字格式，并使其与视觉叙事正交组合。
- 实现三种叙事下的四个主页面，共 12 个完整界面；功能与数据语义保持一致。
- 使用项目内 `docs/design/assets/seasonal-samples/` 样片作为无用户照片时的本地视觉素材；用户真实照片始终优先。

## 开工方式

1. 先运行只读检查，查看当前分支、`git status`、`git diff`、相关文件与完整调用链。
2. 当前 `src/App.tsx` 与 `src/styles.css` 已有其他窗口修改，必须逐段理解并保护，禁止覆盖式重写。
3. 找到页面渲染、设置持久化、数据迁移、备份导入导出和测试后再制定最小改动计划。
4. 按独立版本分支与 PR 规则工作；如果当前环境不适合建分支，先报告，不要破坏现有工作树。

## 实施顺序

### 阶段 1：共享基础

- 新增并迁移 `visualNarrative?: 'archive' | 'light' | 'instrument'`，默认 `archive`。
- 在应用根元素增加独立的视觉叙事属性；不要复用或污染现有 `theme`。
- 建立共享中性、四季、明暗、高对比 token。
- 建立页面语义槽位，确保三套叙事复用数据和交互逻辑。
- 完成设置页视觉叙事选择器及存储失败回滚。

### 阶段 2：典藏

- 依照 `screens/archive/` 和书面尺寸完成四页。
- 先让现有所有记录、编辑、筛选、分享、导入、备份功能无回归。
- 完成空数据、无照片与大数据量状态。

### 阶段 3：光影

- 依照 `screens/light/` 完成四页。
- 照片只进入指定媒体槽位，不作为表单与正文背景。
- 做好无照片降级、解码失败和大量图片性能。

### 阶段 4：刻度

- 依照 `screens/instrument/` 完成四页。
- 每页最多一个主测量图；图形必须有文本等价表达。
- 不实现图片中出现的天气、坐标、医学、校准、光盘或保险库等虚构功能。

### 阶段 5：组合与审阅

- 验证三种叙事 × 浅色／深色／高对比 × 舒适／紧凑。
- 验证 reduced motion、键盘、焦点、对比度和 1280–1920px。
- 生成规范要求的截图，逐项对照 P0/P1 失败条件。
- 运行完整测试、构建 Windows 安装包并生成校验值。
- 写发布说明与 `docs/reviews/` 产品、视觉、数据安全、工程审阅。

## 不可妥协的限制

- 不复制三套业务状态或数据组件。
- 不删除、不弱化现有备份、加密、恢复与危险操作保护。
- 不增加账号、云端、社交、AI、天气、地图、积分或主题商店。
- 不使用蓝紫渐变、玻璃拟态、Bento、卡片海、季节贴纸、大阴影和过度圆角。
- 不为了匹配图片而硬编码示例日期、年龄、统计和照片。
- 不在切换叙事时刷新、关闭抽屉、重置筛选或丢失表单输入。

## 完成定义

只有在以下全部成立时才算完成：

- 12 个页面均真实可用，不是静态截图或仅 CSS 换色。
- 设置选择器可用鼠标和键盘切换，重启后保持，旧数据安全回退。
- 所有现有测试通过，并新增主题迁移、持久化与关键切换行为测试。
- 1440×900 主截图与参考方向一致，1280 和 1920 无溢出。
- 高对比与 reduced motion 可用，正文达到 WCAG AA。
- Windows 安装包可安装，校验值和发布审阅齐全。

如果实现中发现文档与真实数据结构冲突，先保护数据和已有功能，记录冲突与建议，再进行最小范围调整；不得静默改变产品含义。
