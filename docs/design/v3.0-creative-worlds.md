# Memento 3.0.0：四个独立视觉世界

## 设计判断

2.9.0 已经把四页拆成不同的界面语法，但鼠标背景仍然共享同一类装饰思路。3.0.0 将差异推进到渲染层：四页拥有不同的空间、材料、动态来源和阅读节奏，春夏秋冬只作为无用户照片时的本地样片来源。

ui-ux-pro-max 继续负责产品级基础：信息层级、字体与颜色对比、标准控件、键盘焦点、空状态、错误状态和响应式边界。本版本另外采用 GSAP 做轻量 DOM 动效、原生 WebGL 做两个需要连续视觉场的页面；动效层不承载正文和业务状态。

## 四个世界

### 此刻 / Present Lens

- 时间是主角：实时读数、今日位置、年度位置和记录入口围绕左侧阅读面组织。
- WebGL 生成暗色同心时间波纹、水平时间线和随指针变化的暖色镜面，不使用装饰性图片背景。
- 观察窗保持固定尺寸；有用户照片显示生活证据，没有照片则显示日期和记录入口。
- 只做有限的实时呼吸，离开页面或开启 reduced motion 时停止连续运动。

### 时光 / Film Atlas

- 年份轴、月份脊柱和横向记录带是页面骨架。
- 鼠标控制胶片反光带、定位线和小型取景焦点；记录本身仍是可聚焦按钮。
- 有照片和无照片证据格尺寸一致，筛选、月份定位、左右键与 Home/End 不改变。
- 动效只帮助定位与回看，不把页面变成图片瀑布流。

### 几度 / Instrument Bench

- 左侧垂直子 Tab、中央单条真实校准尺、右侧读数和下方列表构成测量仪器。
- WebGL 只绘制低亮度同心刻线、刻度外圈、指针十字和真实进度扫线；实际数字、单位、日期和解释仍由 React/SVG 阅读层提供。
- 不使用照片、不增加虚构仪表数据、不使用 KPI 卡片阵列。

### 我的 / Registry Desk

- 目录栏 + 当前设置文档保留稳定、可预测的设置体验。
- 鼠标只影响纸面上的淡墨圈和两条索引线，帮助页面有生命感但不干扰危险操作。
- 备份、导入、恢复、清空、密码输入和确认提示保留原调用链。

## 技术边界

- CreativeWorld 为四页提供统一指针采样、data-world-effect 标识和装饰生命周期，但每个世界拥有不同的渲染内容。
- 只使用 transform、opacity、局部裁切和画布绘制；不动画化布局尺寸和正文位置。
- WebGL 编译失败会把画布标记为 fallback，并保留实色阅读面；高对比和 reduced motion 隐藏非关键装饰。
- visualNarrative 继续保留在旧数据和备份中，但不参与 3.0.0 页面布局。
- 记录、照片、筛选、详情抽屉、编辑、分享、导入、导出、恢复与清空保护不由视觉层复制或改写。

## 验收要点

- 四页根节点分别具有 data-layout：darkroom-live-time、film-index、precision-instrument、personal-registry。
- 四页根节点分别具有 data-world-effect：present、film、instrument、registry。
- 1280–1920px 不产生横向溢出；键盘焦点不丢失。
- 高对比模式仍显示标题、日期、数字、表单和操作；reduced motion 不保留大范围移动或延迟。
