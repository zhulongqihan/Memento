# v1.5.0 发布后自我审阅

状态：已完成版本审阅；第一代 v1.x 稳定性收口完成，本地 Windows 安装包已构建并通过启动冒烟，代码已纳入最终版本链。

## 本轮完成

- 增加渲染错误兜底页面，异常时明确告知本地记录不会被删除，并提供重新打开入口。
- 支持按 Escape 关闭导入预览、记录抽屉和 Moment 详情。
- 记录名称为空时显示可读的错误提示，不再静默阻止保存。
- 记录抽屉和 Moment 详情使用 dialog 语义及 `aria-modal`。
- 几度页 tab 增加 `role=tab` 和 `aria-selected`，图标按钮继续保留可读标签。
- 固化 Windows 安装、升级、导入导出、键盘回归和发布自审检查清单。

## 已验证

- `npm run typecheck` 通过。
- `npm test -- --run` 通过，3 个测试文件、13 个测试全部通过。
- Playwright 验证空名称显示 `请先给这段时间写一个名字。`，按 Escape 可关闭抽屉。
- `npm run tauri:build` 通过；`memento.exe` 启动 3 秒后进程保持运行且窗口响应正常。

## 仍然存在的不足

1. 本机没有第二台干净 Windows 环境，安装、卸载、覆盖升级仍是未完成的外部验证项。
2. 错误兜底页能恢复窗口，但还没有将错误日志导出给用户的入口。
3. dialog 关闭后焦点返回和复杂键盘焦点陷阱尚未完整实现。
4. 当前仍使用 schema v1，替换导入前没有自动恢复快照。
5. GitHub 当前令牌没有创建 PR/Release 权限。

## 风险等级

- P0：暂无已知阻断问题。
- P1：干净 Windows 安装/升级与远程合并发布未完成。
- P2：焦点管理、错误日志导出、恢复快照。

## 下一轮优先事项

- v2.0：升级 schema，增加数据迁移和替换前恢复快照，让本地数据演进可回滚。
