# v2.1.0 发布后自我审阅

状态：候选版本；三类离线 PNG 分享卡已完成，Windows 构建和真实下载回归通过。

## 本轮完成

- Moment 详情页支持生成 PNG 分享卡，包含标题、日期和一句话。
- 经年列表支持生成 PNG 分享卡，使用当前显示单位和数值。
- 余下列表支持生成 PNG 分享卡，包含数量、单位和下一次日期。
- 分享卡使用本地 Canvas 生成，数据不上传，不依赖云端服务。
- 生成后通过浏览器/Windows 默认下载能力保存到文件系统。
- 三类卡片共用统一的尺寸、留白、色彩和中文字体回退规则。

## 已验证

- `npm run typecheck` 通过。
- `npm test -- --run` 通过，4 个测试文件、15 个测试全部通过。
- Playwright 验证 Moment 分享卡下载成功，并人工检查 PNG 内容；经年分享卡下载成功。
- `npm run tauri:build` 通过；`memento.exe` 启动 3 秒后进程保持运行且窗口响应正常。

## 仍然存在的不足

1. 分享卡暂时只有固定模板和固定 1200×630 尺寸，不能选择主题或比例。
2. 目前是下载文件，不是系统级分享菜单，也没有复制到剪贴板。
3. 图片中的字体依赖系统字体回退，不同 Windows 环境的字形可能略有差异。
4. 尚未加入图片压缩、文件大小提示和失败重试的细分反馈。
5. 尚未完成干净 Windows 安装/升级实测与远程 Release。

- P1：系统字体与下载能力存在环境差异。
- P2：主题/比例、剪贴板、细分错误反馈。
