# 4.0.0 数据安全发布后审阅

更新时间：2026-10-23 20:30:54 +08:00。结论：**正式发布后的独立只读复核通过，范围内无 P0/P1 或发布阻断项。**

## 根因修复

异常照片编辑曾把可显示照片当完整引用集合；现在保留原始 ID，合并新增照片，仅按显式移除解除。单元、浏览器及正式安装版 SQLite 验证通过。同页面多 ID 并发曾跨异步边界持有旧索引；提交时同步读取/合并最新索引，屏障及 UI 回归通过，不外推为多标签页事务。

SQLite 归档曾直接复制 WAL 主文件，遗漏已提交事务。现用 VACUUM INTO 一致性导出，并只读重开验证三表全部行、完整性、schema/status 和哈希，最终下载证据已复核。

## 边界

历史一次 APPDATA-only 启动可能解析真实用户数据库，影响未知；之后不读写、迁移或恢复真实数据库，独立 VM 成功不能反证。此前本机 Known Folder 重定向在执行前被工具拒绝，没有该写入，也不换方式绕过。

本次正式程序只在 hosted VM 使用合成数据运行；本机发布后审阅仅只读下载证据。VM 的 WebView2 测试策略限定精确 exe 并恢复原值，不重定向数据目录。
