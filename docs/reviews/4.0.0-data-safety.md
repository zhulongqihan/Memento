# 4.0.0 数据安全审阅

更新时间：2026-10-23 19:50:52 +08:00。结论：正式候选及下载证据独立复核通过，原生交付和 SQLite 归档 P1 关闭；无已知未关闭范围内 P0/P1。

## 根因与修复

异常照片编辑曾把可显示照片当完整引用集合。现在保留原始 ID，合并新增照片，仅按显式移除解除关联；单元、真实浏览器 UI 与正式安装版 SQLite 验证通过。

浏览器不同 ID 并发写入曾持有跨异步边界的旧索引。提交时同步读取/合并最新索引，屏障测试与三图 UI 回归通过；该结论限同页面，不宣称多标签页事务。

SQLite 证据原先直接复制 WAL 主 DB，遗漏已提交事务。现使用 VACUUM INTO 导出一致性文件，再只读重开，对三表全部行、完整性、schema/status 和 hash 验证。

## 正式产物与下载复核

[候选 39946676016](https://github.com/zhulongqihan/Memento/actions/runs/39946676016) 运行真实 3.1.0 与 v4 正式程序，覆盖旧表升级、迁移失败保留及重试、坏图编辑、替换恢复和卸载保留。

独立只读审查下载的 failure-state.db（schema 3/failed）与 migrated-state.db（schema 4/committed）；完整性、文件 hash、三表逐行结果与报告一致。成功 current 和两 recovery 保留旧时刻、经年、余下、阶段、每日一行、旁白使用/收藏和全部设置。归档的 69 字节合成照片与旧嵌入字节、索引和报告 SHA-256 一致：D3C936EBDD73F46E6422D5946044C99D524554082272019AB738800318B04892。

导入失败只回滚本次新增资产；文件写入不覆盖已有文件；替换/清空前保留快照。加密旧版 fixture 按实际 3.1.0 envelope 生成，是合成兼容样本。

## 边界

历史一次 APPDATA-only 启动可能解析真实用户数据库，影响未知。此后不读写、迁移或恢复真实 DB；独立 VM 通过不能反证。此前本机 Known Folder 重定向在执行前被工具拒绝，没有该写入，也不换方式绕过。

本次正式程序运行仅在 hosted VM；VM 的 WebView2 策略仅限定精确 exe，结束时恢复，不重定向数据目录。最终发布仍须核对 tag 对应文件与下载证据。历史诊断见 [5530cdc 审阅](https://github.com/zhulongqihan/Memento/blob/5530cdcff7ca2759d808aa0a0494d469a2c4b873/docs/reviews/4.0.0-data-safety.md)。
