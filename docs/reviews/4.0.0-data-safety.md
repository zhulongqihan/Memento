## 已修复并复核

- 固定示例 ID 不再触发删除逻辑；没有数据来源元信息时保留记录与照片。回归测试覆盖旧数据。
- 缺失、损坏和未登记的照片会汇总为持久 `role=alert` 提示；删除记录时校验不通过会保留相关索引/文件。
- JSON、ZIP、加密备份显式序列化持久字段，排除 Blob URL `src`。
- AssetStore 写入按 ID 串行化；Tauri 文件提交使用 no-clobber 语义，导入回滚只删除本操作新建的字节。

- 浏览器故障注入使合并导入的状态提交失败；current state、资产文件和索引保持不变；同一备份重试成功。
