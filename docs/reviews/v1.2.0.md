# v1.2.0 发布后自我审阅

状态：候选版本；本地 Windows x64 安装包已构建并完成启动冒烟，待远程 Release 权限补齐后正式发布。

## 本轮完成

- 首页“此刻”的经年、余下和时光记忆支持置顶。
- 时光详情页增加“置顶到首页”入口，置顶状态有明确视觉反馈。
- 删除当前置顶的 Moment 时自动清理失效的置顶引用。
- 经年和余下列表提供置顶操作，首页按置顶 ID 展示，旧数据无置顶字段时回退到第一条。
- 时间轴筛选写入本地设置，刷新应用后仍保留上一次筛选。
- 切换时间轴筛选自动回到顶部，离开时间轴后记录滚动位置，再次进入恢复位置。
- 新增置顶选择的纯函数测试，避免空列表和失效 ID 导致首页异常。
- 版本号、桌面安装包元数据和关于页统一升级至 v1.2.0。

## 已验证

- `npm run typecheck` 通过。
- `npm test -- --run` 通过，3 个测试文件、10 个测试全部通过。
- `npm run build` 通过。
- Playwright 真实交互验证：筛选结果正确、刷新后筛选保持、详情页置顶后首页内容切换成功。
- Playwright 检查 1280px、1440px、1920px 桌面宽度，未发现横向溢出，并保存了三张回归截图。
- Windows `npm run tauri:build` 通过；`memento.exe` 启动 3 秒后进程保持运行且窗口响应正常。

## 仍然存在的不足

1. 时间轴滚动位置目前只在当前应用会话内恢复；重启应用后不恢复页面滚动位置，这属于刻意限制，避免把临时阅读位置写入长期数据。
2. 经年、余下的置顶按钮已经可用，但列表中的“更多”按钮还没有展开菜单，暂时只有置顶这一项操作。
3. “替换本机数据”仍没有在替换前自动生成恢复快照，误操作保护需要在 v2.0 的 schema 与备份机制中完成。
4. 照片仍以内嵌 Data URL 保存在本地数据中，大量照片会增大备份体积，计划在 v2.0 迁移为资源文件索引。
5. 尚未在干净 Windows 环境完成安装、卸载、升级链路验证。
6. GitHub 当前令牌没有创建 Pull Request 和修改默认分支的权限，只能先推送功能分支，远程合并与 Release 仍需仓库权限补齐。
