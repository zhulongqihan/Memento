# v2.4.0 发布后自我审阅

## 版本目标

本轮把“显示与主题”做成用户可随时调整、且不会改变记录数据的偏好层：浅色/深色/高对比主题、舒适/紧凑页面密度、普通/千位分组数字显示。

## 已完成

- `Settings` 增加 `theme`、`displayDensity`、`numberFormat` 可选字段，旧数据读取时自动补默认值。
- 根界面通过 `data-theme` 和 `data-density` 统一驱动 CSS 变量与密度规则，避免在业务组件内散落主题判断。
- 首页“经年”“余下”和“我的”统计数字响应千位分组偏好。
- 偏好和记录使用同一套本地保存链路，刷新后保持不变。
- 主题选择保留键盘可操作的原生 `select`，主题颜色沿用现有焦点轮廓和 accent 体系。
- 版本号同步到前端、Tauri、Cargo、锁文件和备份清单。

## 不足与风险

- P1：本轮只在当前开发机完成启动和安装包构建，尚未在独立的干净 Windows 用户环境完成安装、升级、卸载闭环。
- P2：应用当前最小布局宽度仍为 1160px，紧凑模式改善了纵向信息密度，但没有解决小窗口自适应。
- P2：深色主题覆盖主界面和抽屉，但系统级窗口标题栏颜色仍由 Tauri/Windows 配置决定。
- P3：数字分组目前只覆盖主要统计数字，百分比和日期仍保持原有格式，避免把百分比小数误格式化。
