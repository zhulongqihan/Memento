# v1.3.0 发布后自我审阅

状态：候选版本；本地构建和桌面交互回归通过，待远程 PR/Release 权限补齐后正式发布。

## 本轮完成

- 经年支持天、周、月、年四种显示单位，首页卡片与“几度”列表使用同一偏好。
- 经年支持最近编辑、开始最早、经过最长三种排序。
- 显示单位和排序均写入本地设置，刷新后保持。
- 对未来开始日期继续采用 0 天、0 周、0 月、0 年的安全边界，不展示负数时间。
- 增加经年显示转换单元测试，并保持旧状态字段缺失时回退到“天/最近编辑”。

## 仍然存在的不足

1. 月份按固定平均月长 30.4375 天换算，适合时间感知，不等价于自然月精确计算。
2. 排序只作用于经年列表，首页仍只展示一个置顶项，尚未提供多项并列摘要。
3. 新建经年后暂时没有编辑入口，后续需要统一计数器编辑模型。
4. 尚未完成干净 Windows 环境的安装、卸载和升级验证。
5. GitHub 当前令牌仍不能创建 PR 或 Release，只能推送功能分支。
