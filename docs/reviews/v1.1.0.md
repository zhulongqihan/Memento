# v1.1.0 发布后自我审阅

状态：候选版本，待 Windows 安装包和远程 Release 完成后转为正式发布记录。

## 本轮完成

- Moment 详情增加编辑入口。
- 编辑时加载原有标题、日期、类型、地点、文字和照片。
- 编辑后清理被移除的旧照片引用。
- 时间轴筛选支持全部、初见、今年第一次、人生节点和今年。
- JSON/ZIP 导入增加备份摘要预览。
- 导入支持合并导入和替换本机数据。
- 合并按 ID 和 `updatedAt` 处理，不覆盖本机不同记录。
- 增加合并函数测试和版本自审文档。

## 已验证

- TypeScript 检查通过。
- 日期与备份合并测试 8/8 通过。
- Vite 生产构建通过。
- 编辑 Drawer 真实交互通过。
- 时间轴“今年第一次”筛选真实交互通过。
- 备份预览、合并导入和记录数变化真实交互通过。

## 仍然存在的不足

1. 尚未在干净 Windows 环境执行安装、卸载和升级全流程。
2. 当前“替换本机数据”没有单独的用户可见恢复快照入口。
3. 时间轴筛选状态不会写入 URL 或本地偏好，重启后回到“全部”。
4. 照片仍以 Data URL 存储，后续需要迁移到更适合大文件的资源文件结构。
5. GitHub 当前 token 没有创建 Pull Request 的权限，正式 Release 仍需权限补齐。

## 风险等级

- P0：暂无。
- P1：干净 Windows 安装与升级尚未验证；远程 PR/Release 尚未完成。
- P2：替换前快照、照片资源文件化、筛选偏好持久化。

## 下一轮优先事项

- v1.2：稳定时间轴筛选、置顶和回到原位置。
- 完成 Windows 安装包的真实安装与卸载验证。
- 在 GitHub 权限允许后创建 PR 并发布安装包。
