# v2.2.0 发布后自我审阅

状态：候选版本；自定义星期单位、真实记录流程、Windows 构建和启动冒烟通过。

## 本轮完成

- 余下新增“自定义星期”单位，可从周一到周日任意选择一个或多个。
- 自定义选择保存到 `RemainingCounter.weekdays`，旧的周五、周六、周日、周末数据保持兼容。
- 首页、几度列表和余下分享卡统一使用同一组自定义星期计算结果。
- 自定义星期为空时禁止保存，并显示可读错误提示。
- 新增确定性日期计算测试，验证只返回用户选择的星期且遵守截止日期。

## 已验证

- `npm run typecheck` 通过。
- `npm test -- --run` 通过，4 个测试文件、16 个测试全部通过。
- Playwright 真实流程验证：选择周一/周三、保存“自定义工作日”，列表显示 8.24 周一、8.26 周三等对应日期，未混入其他星期。
- `npm run tauri:build` 通过；`memento.exe` 启动 3 秒后进程保持运行且窗口响应正常。

## 仍然存在的不足

1. 已保存的自定义星期暂时只能在新建时设置，还没有余下条目的编辑入口。
2. 星期选择使用固定周一到周日顺序，没有本地化的周起始日偏好。
3. 自定义日期仍按当前本地日历计算，尚未支持节假日或工作日例外表。
4. 尚未完成干净 Windows 安装/升级实测与远程 Release。

## 风险等级

- P0：暂无。
- P1：暂无已知核心计算阻断。
- P2：编辑入口、周起始日、节假日例外。
