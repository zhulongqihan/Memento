# 4.0.0 产品审阅

更新时间：2026-10-23 18:04 +08:00。状态：实现与浏览器复核通过，正式 Windows 产物待验收，暂不进入发布 PR。

## 已核对

- 四页维持记录、查看、计算、备份职责，没有扩张账户、云端、社交等产品边界。
- 经年、余下、刻度编辑回填原名称；暂停刻度可管理和重启，不继续出现在主测量。
- 经年和余下支持单条删除，清理相应置顶；三张照片均可完整查看。
- 历史每日一行可按月找回、修改、删除，编辑保持原日期，符合保存并重看时间的承诺。
- 缺失/损坏照片有占位与主动移除入口，文字编辑保留原关联。
- 生产构建的 UI 验证覆盖保存、重载、删除、导入和恢复，无页面异常。
