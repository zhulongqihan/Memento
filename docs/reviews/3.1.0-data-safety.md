# 3.1.0 数据安全审阅

审阅日期：2026-08-28

## 结论

通过。用户数据继续保存在本地 SQLite；文案库为项目内只读资源，运行时没有文案 API 请求。每日一行、旁白使用历史和收藏旁白快照进入同一份应用状态与备份链路。

## 保护点

- v1/v2 数据自动迁移为 schema v3，缺少新增集合时安全补空数组。
- JSON、完整 ZIP、AES-GCM 加密备份都包含新增内容；备份预览数量以实际迁移数据为准。
- 替换导入和清空数据前仍保存本地恢复快照。
- 清空数据同时清除每日一行、旁白历史和收藏快照，并保留可恢复快照。
- 外文条目保留原文、中文编译译文、作者、作品、来源链接和许可信息。
