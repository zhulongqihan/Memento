# 产品审阅：四季 × 三种视觉叙事

审阅对象：`visualNarrative` 与四个主页面的三种编排。

## 结论

- 通过：四个页面映射保持为春·此刻、夏·时光、秋·几度、冬·我的。
- 通过：记录、筛选、几度子 Tab、表单、分享、导入、导出、恢复入口复用原业务逻辑。
- 通过：切换叙事不刷新应用、不关闭设置页、不改变 `theme`、密度和数字格式。
- 通过：旧设置与未知叙事值回退到典藏。

## 风险

- P2：真实用户照片数量较大时的解码/虚拟化仍需在真实大数据集上复核。
- P2：真实照片大数据集仍需补测；备份导出、错误密码拒绝、正确密码替换导入和快照保留已在隔离浏览器存储完成。
