# v1.0.0 首轮发布前审阅

状态：待 Windows 安装包构建完成后最终确认。

## 已验证

- 1440×900 首屏通过浏览器实际截图检查。
- 主页、时光、几度、我的四页可以切换。
- 记录 Drawer 可以创建 Moment、经年、余下和刻度。
- 创建经年后可以在“几度 / 经年”列表看到新记录。
- 历史 Moment 的相对时间显示为“多少天前”。
- 日期计算测试 6/6 通过。
- TypeScript 检查通过。
- Vite 生产构建通过。
- favicon 资源不再产生 404。

## 当前不足

1. Moment 已支持创建和删除，但编辑功能尚未完成。
2. 导入当前采用整体替换策略，合并导入和替换前快照将在后续版本补齐。
3. 目前尚未在干净 Windows 环境完成安装、卸载和 WebView2 缺失场景验证。
4. 照片备份已经写入 ZIP 数据，但还需要做大图片和损坏文件的专项验证。
5. 时间轴筛选按钮目前只有视觉状态，筛选逻辑将在 v1.2.0 完成。

## 风险级别

- P0：暂无已知问题。
- P1：Windows 安装包尚未完成最终验证。
- P2：编辑、筛选、备份合并策略尚未完成。
