# 4.2.0 产品与视觉验收

日期：2026-11-05。本文为修复后的验收；修复前独立设计判断见 [严格评审](4.2.0-strict-review.md)。没有把自动测试通过转换为新的主观评分。

## 产品路径

- 编辑原记录时再次选择当前类型不会转为新增；新增、编辑与照片修改的关闭保护一致，取消放弃会保留草稿与焦点。
- 今日一行的日期随本地日更新；已经开始的跨日草稿显示明确原日期，不静默写到新一天。删除和空文本保存的含义清楚且独立。
- 从时光切到其他页面再返回，保留搜索与索引/胶片选择。长地点可在详情完整阅读，预览不会撑宽页面。
- 人生年限验证在保存前发生，错误不改变已保存值。设置页区分日常备份、加密、恢复和清空，普通导出失败会说明原因。

## 视觉结果

| 页面 | 改善与实际检查 |
| --- | --- |
| 此刻 | 深绿底保留，强化真实记忆标题与正文，时钟与记录形成两栏；首次空态聚焦单一内容区入口。旁白、今日一行与主记录层级更清晰，装饰透明度降低。 |
| 时光 | 日期、标题、分类和摘要有稳定层次，月份导航保持；无照片条目去掉多余装饰条。长标题/摘要在列表省略，详情完整换行。暗色标题与主要动作恢复可读。 |
| 几度 | 测量值与操作列保持分离，主测量字号与辅助字提升，空态按钮可读；舒适行高约 114px，紧凑约 94px，控制仍至少 32×32px。 |
| 我的 | 目录与正文形成清晰主次，完整 ZIP 为主要备份动作，加密入口直接可见，清空独立放置。数据、人生、阅读、旁白和关于均检查三种主题。 |

共享规则使用无衬线操作字体、衬线记忆标题、等宽时间数字；过场缩为 180ms，内容默认可见，reduced motion 下不运行页面装饰动画。保留四页不同身份，不添加新功能方向。

## 运行证据

最终生产构建本地通过 116 项视觉与边界检查：四页×1280×720、1440×900、1920×1080×浅色/深色/高对比；另有设置子页、空态、极长标题/英文地点/多行笔记、两种密度、年限非法与上下边界、reduced motion。页面运行错误为空。关键正文/动作对比按 4.5:1、大字按 3:1 检查。

主流程实际看过此刻与时光的私人副本正常动画截图、深色时光/设置/旁白、首次空态、几度空态、长详情和两种密度截图。自动检测不能替代这些人工判断，也不代表完整 WCAG、读屏或所有缩放条件认证。

生产构建的 8 组状态流程通过；原有 13 组浏览器回归、6 组阅读检查亦通过。Windows hosted 最终候选重复通过这些检查和 8 项原生验收。下载后实际查看原生新装首屏与恢复照片页面，两者均为 1440×900、无横向溢出，记录与操作可读。最终同字节安装包结果见 [候选说明](../releases/4.2.0.md)。

## 真实场景与边界

本轮继续使用上次秋招副本的 83 条时刻、4 条经年、4 条余下和 41 条每日一行，8 项复测通过，业务记录保持原样。日期预期按当前运行环境独立计算，因此已过去的节点显示“已过”，不再固定要求显示“今天”。

当前桌面源表的哈希与首次采样不同，说明源文件后来有变化；本轮没有重建样本，也没有改写源表，因此该副本只用于体验与回归，不作为最新投递状态。私人源数据与截图未上传。
